# Present Simple


!!! note
    This is a rule

## Use
We use Present Simple for routines and habits.

## Form
Subject + base verb (add -s in 3rd person singular)

## Example
I go to work every day.
She studies English.

## Negative
I do not (don’t) like coffee.
